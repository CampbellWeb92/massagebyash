MASSAGE BY ASHLEIGH WEBSITE
===========================

Open index.html to preview the website locally.

Files:
- index.html: main website content
- assets/css/styles.css: all main website styling
- assets/css/legal.css: shared styling for legal pages
- assets/js/main.js: age gate, mobile menu, WhatsApp booking, gallery and business-hours logic
- privacy-policy.html, booking-terms.html, disclaimer.html: legal pages
- image files: website and gallery images
- CNAME and robots.txt: deployment files

The website is ready for static hosting. Upload the full folder contents together so all relative paths remain intact.
