MASSAGE BY ASHLEIGH WEBSITE
===========================

Open index.html to preview the website locally.

MAIN FILES
----------
- index.html: main website content
- assets/css/styles.css: main website styling
- assets/css/legal.css: shared styling for legal and 404 pages
- assets/js/main.js: age gate, booking validation/calculator, mobile menu, gallery and business-hours logic
- privacy-policy.html, booking-terms.html, disclaimer.html: legal pages
- 404.html: custom page-not-found screen
- sitemap.xml and robots.txt: search-engine files
- logo.webp: optimized transparent logo
- hero-desktop.webp and hero-mobile.webp: responsive hero images

DEPLOYMENT
----------
Upload the full folder contents together so all relative paths remain intact. The site is suitable for static hosting.

BOOKING FORM RULES
------------------
- Tuesday to Friday: 09:00–17:00
- Saturday: 09:00–15:00
- Sunday and Monday: unavailable
- Strictly by appointment
- Available start times adjust to the selected appointment duration
